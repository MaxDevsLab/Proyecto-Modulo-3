🖥 Aplicación de Consola JS

Esta app se ejecuta en la consola del navegador. Sigue los pasos para abrirla y comenzar.

1

Abre la Consola del Navegador

Presiona el atajo de teclado correspondiente a tu sistema operativo (ver abajo). O haz clic derecho → "Inspeccionar" → pestaña "Consola".

2

Al abrir la consola escribe la fxiniciarApp()

El archivo app.js ya está enlazado. Al abrir la consola y ejecutar la fx verás los mensajes de las 5 lecciones ejecutándose.

3

Responde los prompts interactivos

La app pedirá datos como tu nombre y números para realizar operaciones. Escríbelos en las ventanas emergentes.

4

Explora el código en app.js

Cada lección está separada con comentarios. El código está documentado paso a paso para facilitar el aprendizaje.
